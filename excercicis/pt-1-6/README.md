# Explicación del ejercicio
En este ejercicio teniamos que crear una VPC, subredes 1 publica y el resto privadas con 1 instancia cada subred, ademas de esto teniamos que conseguir que la instancia que se encuentra en la subred publica funcione como un bastion por donde pasariamos para posteriormente conectarnos a las maquinas de las subredes privadas.
