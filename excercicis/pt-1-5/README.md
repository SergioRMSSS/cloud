# Explicación del ejercicio
En este ejercicio creamos muchos mas ficheros .tf, los cuales nos permiten tener un mayor control sobre lo que queremos hacer.
Trabajamos con un fichero llamado "variables.tf" el cual amacena variables las cuales usamos en el fichero "main.tf" en el cual como en anteriores practicas se
ha usado para tener detro de el todo lo que queremos crear en nuestro proveedor AWS, tambien hemos implementado un fichero llamado "outputs.tf" en el cual configuramos
para que una vez hecho el "terraform apply" nos de algunos datos que querramos sobre maquinas o de mas cosas. Y por ultimo hemos implementado un fichero llamado 
"provider.tf" en el cual especificamos a traves de una variable que region usamos.
